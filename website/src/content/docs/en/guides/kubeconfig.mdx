## Overview

The **Kubeconfig** page lets you manage the `~/.kube/config` file — the standard Kubernetes
credential file used by `kubectl`, `helm`, `k9s`, and other tools.

## Exporting a Cluster's Kubeconfig

From the Clusters page, click **Export Kubeconfig** on any running cluster.
K3Desktop merges the cluster's credentials into `~/.kube/config`, creating or updating
the relevant context, cluster, and user entries.

## Viewing the Raw Kubeconfig

The **Kubeconfig** page shows the full `~/.kube/config` as YAML.
This is read-only — edit the file directly if you need to make manual changes.

## Context Management

| Action | Description |
|--------|-------------|
| **Set Active** | Switch `current-context` to the selected context |
| **Delete** | Remove the context (and its associated cluster/user entries if orphaned) |

<Aside type="tip">
After creating a cluster, export its kubeconfig and set it as the active context.
Then `kubectl get nodes` will target that cluster.
</Aside>

## Multiple Clusters

K3Desktop supports multiple clusters simultaneously. Each export merges cleanly — contexts
are namespaced by cluster name so they don't overwrite each other.

```bash
# List all contexts after exporting multiple clusters
kubectl config get-contexts
```
