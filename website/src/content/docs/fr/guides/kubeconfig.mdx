## Vue d'ensemble

La page **Kubeconfig** vous permet de gérer le fichier `~/.kube/config` — le fichier d'identifiants standard de Kubernetes utilisé par `kubectl`, `helm`, `k9s` et d'autres outils.

## Exporter le Kubeconfig d'un Cluster

Depuis la page Clusters, cliquez sur **Exporter Kubeconfig** sur n'importe quel cluster en cours d'exécution.
K3Desktop fusionne les identifiants du cluster dans `~/.kube/config`, en créant ou mettant à jour les contextes, clusters et utilisateurs concernés.

## Affichage du Kubeconfig Brut

La page **Kubeconfig** affiche l'intégralité de `~/.kube/config` au format YAML.
C'est en lecture seule — modifiez le fichier directement si vous avez besoin de changements manuels.

## Gestion des Contextes

| Action | Description |
|--------|-------------|
| **Définir Actif** | Change `current-context` vers le contexte sélectionné |
| **Supprimer** | Supprime le contexte (et les clusters/utilisateurs associés s'ils sont orphelins) |

<Aside type="tip">
Après avoir créé un cluster, exportez son kubeconfig et définissez-le comme contexte actif.
Ensuite, `kubectl get nodes` ciblera ce cluster.
</Aside>

## Clusters Multiples

K3Desktop prend en charge plusieurs clusters simultanément. Chaque exportation est fusionnée proprement — les contextes sont nommés selon le cluster pour éviter les écrasements.

```bash
# Lister tous les contextes après avoir exporté plusieurs clusters
kubectl config get-contexts
```
