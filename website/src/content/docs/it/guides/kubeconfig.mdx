## Panoramica

La pagina **Kubeconfig** ti permette di gestire il file `~/.kube/config` — il file standard delle credenziali Kubernetes usato da `kubectl`, `helm`, `k9s` e altri strumenti.

## Esportare il Kubeconfig di un Cluster

Dalla pagina Clusters, clicca su **Esporta Kubeconfig** su qualsiasi cluster in esecuzione.
K3Desktop unisce le credenziali del cluster in `~/.kube/config`, creando o aggiornando i relativi context, cluster e user.

## Visualizzare il Kubeconfig Grezzo

La pagina **Kubeconfig** mostra l'intero `~/.kube/config` come YAML.
È in sola lettura — modifica il file direttamente se hai bisogno di cambi manuali.

## Gestione dei Contesti

| Azione | Descrizione |
|--------|-------------|
| **Imposta Attivo** | Cambia `current-context` al contesto selezionato |
| **Elimina** | Rimuove il contesto (e i relativi cluster/user se orfani) |

<Aside type="tip">
Dopo aver creato un cluster, esporta il suo kubeconfig e impostalo come contesto attivo.
Poi `kubectl get nodes` punterà a quel cluster.
</Aside>

## Più Cluster

K3Desktop supporta più cluster contemporaneamente. Ogni esportazione viene unita correttamente — i contesti sono namespaced per nome cluster così non si sovrascrivono.

```bash
# Elenca tutti i contesti dopo aver esportato più cluster
kubectl config get-contexts
```
