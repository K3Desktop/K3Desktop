## Panoramica

I **Profili** sono configurazioni di cluster k3d salvate come file YAML in
`~/.config/k3desktop/profiles/`. Un profilo cattura una specifica cluster completa — numero nodi,
mapping porte, volumi, variabili ambiente, argomenti k3s, setup registry e altro — così puoi ricreare cluster identici con un click.

## Creazione di un Profilo

Apri **Nuovo Cluster → Avanzato**. Configura il cluster, poi clicca **Salva come Profilo** e dai un nome. L'editor YAML corrente viene salvato in `~/.config/k3desktop/profiles/<nome>.yaml`.

Puoi anche creare o modificare profili direttamente dalla pagina **Profili**.

## Caricamento di un Profilo

Da **Nuovo Cluster → Avanzato**, clicca **Carica Profilo** e seleziona un profilo salvato. L'editor si popola con lo YAML del profilo, che puoi modificare prima della creazione.

## Importazione di un Profilo

Clicca **Importa** nella pagina Profili. Si apre un selettore file — scegli un qualsiasi file YAML k3d v1alpha5 valido dal filesystem. K3Desktop valida lo YAML e lo copia nella directory dei profili. Se esiste già un profilo con lo stesso nome, il file importato viene salvato con suffisso `-imported`.

<Aside type="tip">
I profili sono semplici file YAML. Puoi versionarli, condividerli con il team o scriverli a mano usando la [reference file di configurazione k3d](https://k3d.io/stable/usage/configfile/).
</Aside>
