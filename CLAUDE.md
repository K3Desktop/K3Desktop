# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
# Dev mode (hot-reload for both Go and Svelte)
task dev

# Build for current OS
task build

# Run built binary
task run

# Build/run as headless HTTP server (no native GUI)
task build:server
task run:server

# TypeScript type-check (frontend only)
cd frontend && npm run check

# Regenerate TS bindings after changing Go service methods
wails3 generate bindings -clean=true -ts
```

## Architecture

**Wails v3** app: Go backend exposes services; Svelte frontend calls them via auto-generated TypeScript bindings.

### Go backend (`main.go`, `service/`, `dto/`)

- `main.go` — registers four Wails services and opens a single 1200×800 window
- `service/` — one file per domain; each exported method becomes a callable TS binding
  - `runtime.go` — singleton Docker runtime (`GetRuntime()`) via `sync.Once`
  - `cluster.go` — cluster CRUD + start/stop; `CreateCluster` runs asynchronously and emits `cluster:creating` / `cluster:ready` / `cluster:error` Wails events
  - `node.go` — node management per cluster
  - `registry.go` — k3d local registry CRUD
  - `kubeconfig.go` — export to `~/.kube/config` or return YAML
- `dto/` — plain Go structs with JSON tags; both backend and the generated TS bindings use these types

### Frontend (`frontend/src/`)

- **No router library** — `App.svelte` uses a `route` string variable and `{#if}` blocks for navigation
- `src/routes/` — one `.svelte` file per route: `Clusters`, `Nodes`, `Registries`, `Kubeconfig`
- `src/lib/theme.ts` — dark mode writable store; persists to `localStorage`, toggles `dark` class on `<html>`
- Tailwind CSS v4; custom `text-brand` / `bg-brand` colors defined in `app.css`
- **`frontend/bindings/`** is fully auto-generated by `wails3 generate bindings` — never edit it manually. Imports look like:
  ```ts
  import { ClusterService } from "../../bindings/github.com/k3desktop/k3desktop/service";
  import { ClusterDTO } from "../../bindings/github.com/k3desktop/k3desktop/dto";
  ```

### Adding a new backend method

1. Add the method to the appropriate `service/*.go` file (receiver on the `*Service` struct)
2. Add/update the DTO in `dto/` if needed
3. Run `wails3 generate bindings -clean=true -ts` to regenerate `frontend/bindings/`
4. Import and call from the relevant Svelte route

### Gotchas

- `go build ./...` from project root fails (iOS build artifact); use `go build ./service/... ./dto/...` to verify Go packages
- `sigs.k8s.io/yaml` is an indirect dep; run `go get sigs.k8s.io/yaml` if a service file imports it directly
- `k8s.io/client-go` and `k8s.io/apimachinery` are direct deps — use `kubernetes.NewForConfig` + `clientcmd.NewDefaultClientConfig(*kubecfg, nil).ClientConfig()` to talk to the cluster API programmatically; prefer this over `rt.ExecInNode` with `kubectl`
- `service/kubeconfig.go` owns context CRUD (`ListContexts`, `SetCurrentContext`, `DeleteContext`); delete also prunes dangling cluster/user entries from the kubeconfig file
- `Dialog.OpenFile().AddFilter(displayName, pattern string)` — pattern is one string (`"*.yaml;*.yml"`), not variadic
- Svelte `<script>` imports: omit `.ts` extension (requires `allowImportingTsExtensions` otherwise); `.svelte` extension is fine
- `service/profile.go` owns `advancedRequestToSimpleConfig` / `simpleConfigToAdvancedRequest` — canonical mapping, don't duplicate
- Svelte 5: DOM bind refs and reactive locals need `$state()` — `let el: HTMLDivElement | undefined = $state()`, not a bare `let`
- `application.Get()` returns nil during early Go init before the Wails app is ready — guard before calling `.Event.Emit`
- `application.RegisterEvent` is typed — e.g. `RegisterEvent[dto.LogEntryDTO]("log:entry")`; type must match `Emit` payload
- k3d logs via `github.com/k3d-io/k3d/v5/pkg/logger.Logger` (`*logrus.Logger`) — inject via `AddHook` + `SetOutput(noopWriter{})`
- Custom `slog.Handler` must implement `WithAttrs` and `WithGroup` (even if just wrapping the inner handler)
- `Events.On("event", cb)` registers a **global** listener — calling the returned `off()` removes ALL listeners for that event name, not just the one registered. For multiple concurrent subscribers use a shared Svelte writable store fed by one `Events.On` in `logStore.ts`.
- `k3dclient.ClusterRun` does NOT merge kubeconfig — only the k3d CLI does. After `ClusterRun` succeeds, call `k3dclient.KubeconfigGetWrite(..., &WriteKubeConfigOptions{UpdateExisting: true, UpdateCurrentContext: ...})` manually if `KubeconfigOpts.UpdateDefaultKubeconfig` is set.
- `service/logger.go` owns `WithTarget(name) func()` — registers current goroutine ID → name in `goroutineTarget sync.Map`; call `defer WithTarget(name)()` at the start of any service method to stamp `Target` on all logs emitted from that goroutine (including k3d logrus logs).
- Color roles: `brand` = lime `#CDF700` (button backgrounds, use `text-gray-900` not `text-white`); `accent` = cyan `#0DCEFF` (focus rings, active text, links). Grays are neutral/no blue tint; `gray-900 = #1A1A1A` matches k3d dark bg.
- Custom `<select>` styling: global `appearance: none` + SVG chevron via `background-image` in `app.css`; use `bg-white dark:bg-gray-800` (not `bg-transparent`) so the chevron is visible.
- Native `<select>` inside a WebView2 modal closes on `mouseup` — use a custom button+listbox (`$state` open flag + `{#if}` panel) for any dropdown inside a modal overlay
- Node upgrade blue-green replace: (1) rename old node to free the name, (2) re-fetch cluster so `NodeAddToCluster` sees the renamed container, (3) use `cleanStaleNodeState` to delete the k8s Node object and `<name>.node-password.k3s` secret before creating replacement — stale password hash → permanent 403; stale flannel annotations (`public-ip`) → networking crash in new container
- Server node upgrade is not feasible with SQLite/kine datastore: cluster state lives in a container-specific Docker volume inaccessible to a new container — hide Upgrade for `role === "server"` nodes
- `ListNodes` / any `ClusterGet` call can hang: `GetLoadbalancerConfig` does `ReadFromNode` (Docker `CopyFromContainer`) on the LB container; wrap with `context.WithTimeout` (10s) to prevent indefinite block
- `helm.sh/helm/v3` is a direct dep — add via `go get helm.sh/helm/v3/pkg/action helm.sh/helm/v3/pkg/chart/loader helm.sh/helm/v3/pkg/cli` (module root alone doesn't work)
- Helm `action.Upgrade` has no `CreateNamespace` field — that's on `action.Install` only. Upgrade-or-install: check `action.NewHistory(...).Run(releaseName)`; if `driver.ErrReleaseNotFound` → `action.NewInstall` with `CreateNamespace=true`, else `action.NewUpgrade`
- `action.Pull` with `Untar=true` untars into `UntarDir/<chart-name>/`, not `UntarDir/` directly — use `filepath.Join(pull.UntarDir, entry.Chart)` to load
- Wails events carrying multiple fields need a DTO payload, not `string` — e.g. `application.RegisterEvent[dto.BlueprintEventDTO]("blueprint:error")`; type must match `Emit` payload
- `src/lib/theme.ts` also owns `sidebarWidth` and `sidebarCollapsed` stores (persisted to `localStorage`); Sidebar receives them as plain props + `onWidthChange`/`onCollapsedChange` callbacks, not `$bindable`
- Svelte `flex-1` without `min-w-0` lets long text overflow parent — always pair: `flex-1 min-w-0 break-words`
- `service/blueprint.go` owns blueprint CRUD + Helm deploy; blueprints stored at `~/.config/k3desktop/blueprints/<name>.yaml`
- `rt.StopNode` / `rt.StartNode` are thin `docker stop` / `docker start` wrappers — use them directly for restart. `k3dclient.NodeStart` adds pre-start hooks (DNS fix, CgroupsV2) only needed on fresh container creation, not restarts.

### Async events pattern

Long-running operations (e.g. cluster creation) use Wails events instead of blocking the RPC:

```go
// Go: register in init(), emit from goroutine
application.RegisterEvent[string]("cluster:ready")
app.Event.Emit("cluster:ready", clusterName)
```

```ts
// Svelte: listen via @wailsio/runtime
import { Events } from "@wailsio/runtime";
Events.On("cluster:ready", () => { ... });
```
